# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my introduction, technical skills, projects, and contact information in one place.

## 📌 About the Project

This is a simple personal portfolio website built using HTML. It is designed to introduce me as a web developer, highlight my technical abilities, and provide visitors with information about my projects and background.

## ✨ Features

- **Welcome Section:** A brief introduction about me.
- **About Me:** Profile picture and personal introduction.
- **My Projects:** Showcases my machine learning and web development projects.
- **Technical Skills:** Displays my technical skills and proficiency levels.
- **Contact Form:** Allows visitors to enter their name, email, and message.
- **Social Links:** Provides quick access to my online profiles.

## 🛠️ Technologies Used

- HTML5
- Basic HTML forms and tables
- Hyperlinks and images
- Semantic HTML elements

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Neexav0/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Open `Portfolio.html` in your preferred web browser.

No additional installations or dependencies are required.
